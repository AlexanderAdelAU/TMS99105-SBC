This is a native Relocatable Assembler and runs on the TMS99105 SBC.  It loads at 0x1000 and the R99 object is produced by default.   The production of the Assembly Listing is optional.


Shell Version 6.3
TMS99105 SBC V4 - Paged Memory
%R99

Usage: R99 <file> [options]
  -L   listing to <file>.L99
  -LX  listing to console
  -LY  listing to list device
  -N   syntax check only (no .R99 object)
  -R   object output (.R99, default)
  -H   same as -R (compatibility)
  -S   accepted for compatibility
%
